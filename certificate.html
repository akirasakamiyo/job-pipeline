Sertifikat penyelesaian

Terbuka setelah kelima modul selesai dan Evaluasi Akhir lulus. Sertifikat dibuat sebagai PDF langsung di browsermu dari data belajar yang tersimpan di perangkat ini.

Status sertifikat

Batasan sertifikat ini

  • Bukan sertifikasi resmi. Sertifikat ini adalah bukti penyelesaian pribadi dari platform belajar mandiri, tidak dikeluarkan atau diakui oleh lembaga, kampus, maupun asosiasi profesi mana pun.
  • Tidak bisa diverifikasi pihak lain. Situs ini berjalan di GitHub Pages: hosting statis tanpa server, akun, atau database. Tidak ada tempat untuk menyimpan dan memeriksa sertifikat secara daring.
  • Data ada di perangkatmu. Progres disimpan di LocalStorage browser, yang bisa diubah atau dihapus oleh pemilik perangkat. Karena itu, hasil di sertifikat tidak dapat dibuktikan ke pihak ketiga.
  • ID sertifikat hanya penanda lokal. ID dibentuk dari tanggal dan nama di perangkat ini (bukan tanda tangan digital). Gunakan untuk arsip pribadimu, misalnya mencocokkan file PDF dengan cadangan data.

Saran: saat melamar, tunjukkan hasil nyata (CV, email lamaran, portofolio) yang kamu buat selama belajar. Itu lebih meyakinkan daripada sertifikat apa pun.
